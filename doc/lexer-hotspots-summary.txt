WHAT TO DO, in the order the numbers suggest
  1. read_ident / convert_universal_chars: an ASCII fast path that skips
     decode_utf8 and the Unicode predicates for bytes < 0x80 (~4-5% together).
  2. canonicalize_and_splice: order the branch chain so the ordinary byte pays
     one test instead of four (~1.5-2%).
  3. isspace/isdigit in tokenize: range tests instead of ctype (~0.5-1%).
  4. intern's hash: 2.23% for 94k lookups, ~129 instructions each.
  5. new_token's emalloc: 1.65%; a token arena would fold it into a pointer bump.
